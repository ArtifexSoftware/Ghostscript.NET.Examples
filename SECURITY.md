# Security Policy

## Supported versions

Use the NuGet package versions pinned in [`Versions.props`](Versions.props) with these examples.

## Reporting a vulnerability

Please do **not** open a public GitHub issue for security-sensitive reports.

Contact Artifex Software, Inc.:

- https://artifex.com/contact
- Or your existing Artifex support channel if you are a commercial licensee

Include the example project name, package versions from `Versions.props`, OS/.NET version, and steps to reproduce when possible.
